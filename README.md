## 💼 오픈소스 기여

### 1. 매출 데이터 정확성 버그 분석 및 수정 기여

edgartools — [`#885`](https://github.com/dgunning/edgartools/issues/885)

NYSE:IONQ의 10-Q 필링에서 `get_revenue()`가 최신 분기 매출 대신 **전년 동기 값을 반환**하는 사일런트 에러(Silent Data Corruption)를 발견하고 재현·분석하여 제보

#### 핵심 분석
get_revenue()가 기간 메타데이터가 아닌 열 위치(index)만으로 최신 기간을 판단하는 구조적 문제를, IonQ FY2025 Q2·Q3 10-Q의 실제 컬럼 순서 불일치 사례로 재현하고 종료일·duration 기반 선택 방식을 제안

#### 메인테이너 대응
컬럼을 위치가 아닌 메타데이터(종료일 + duration) 기준으로 정렬하도록 수정하고, 이를 get_net_income()·get_operating_income()과 label 기반 fallback에도 동일 적용

#### 결과
수정 커밋 [058648b](https://github.com/dgunning/edgartools/commit/058648b8a01c510bff318b9be326debc089c17fc)로 main에 반영되어 [v5.41.0](https://github.com/dgunning/edgartools/commit/058648b8a01c510bff318b9be326debc089c17fc)에 수정 사항이 반영되어 배포

### 2. 운영 현금 흐름 추출 버그 분석 및 수정 기여

edgartools — [`#1083`](https://github.com/dgunning/edgartools/issues/1083)

NASDAQ: AAPL 10-Q에서 `get_operating_cash_flow()`가 운영 현금 흐름을 `None`으로 반환하는 문제를 발견하고, 재현 코드와 예상값을 포함해 원인을 분석·제보

#### 핵심 분석
AAPL의 XBRL 표준 개념(NetCashProvidedByUsedInOperatingActivities)은 [xbrl 표준화 파일](https://github.com/dgunning/edgartools/blob/main/edgar/standardization/synonym_groups.py)에 정상 존재하지만 함수가 label 기반 정규식만으로 값을 탐색해 "Cash generated by operating activities" 같은 표현을 놓치는 문제를 확인하고, 해당 패턴 추가 및 회귀 테스트를 제안함.

#### 메인테이너 대응
기존 label 기반 탐색에서 XBRL Concept-first lookup → label 기반 fallback 구조로 개선했으며, 이 과정에서 발견된 render(standard=True) 표준화 매핑 부족 문제는 별도 이슈로 분리함.

#### 결과
수정 PR [#1089](https://github.com/dgunning/edgartools/pull/1089)가 main에 병합되어 AAPL 10-Q 운영 현금 흐름이 $82.627B로 정상 추출되었으며, [v5.52.0](https://github.com/dgunning/edgartools/pull/1091) 릴리스 #1091에 포함됨.

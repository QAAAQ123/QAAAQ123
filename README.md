## 💼 오픈소스 기여

### 1. 데이터 정확성 버그 분석 및 리포트

edgartools — [`#885`](https://github.com/dgunning/edgartools/issues/885)

NYSE:IONQ의 `get_revenue()`가 최신 분기 매출 대신 **전년 동기 값을 반환**하는 사일런트 에러(Silent Data Corruption)를 발견하고 재현·분석하여 제보

핵심 분석

* 기간 메타데이터가 아닌 **열 위치에 의존한 데이터 선택 로직**의 구조적 문제 식별
* 10-Q의 현재 기간·전년 비교 기간 및 분기/YTD 데이터가 혼재하는 상황에서 기간 인식 없는 위치 기반 접근의 위험성 분석
* 실제 재현 사례와 원인 코드를 추적해 문제를 구체화

의의

* 재무 데이터 파이프라인에서 데이터 정확성과 검증의 중요성을 확인
* 단순 값 조회가 아닌 회계 기간과 데이터 의미를 기준으로 한 개념 기반 처리의 필요성 제시

### 2. 운영 현금 흐름 추출 버그 분석 및 수정 기여

edgartools — [`#1083`](https://github.com/dgunning/edgartools/issues/1083)

NASDAQ: AAPL 10-Q에서 `get_operating_cash_flow()`가 운영 현금 흐름을 `None`으로 반환하는 문제를 발견하고, 재현 코드와 예상값을 포함해 원인을 분석·제보

핵심 분석

* AAPL의 XBRL 표준 개념 `NetCashProvidedByUsedInOperatingActivities`는 정상적으로 존재하지만, 해당 함수가 **XBRL Concept**이 아닌 **label 기반 정규식으로만 값을 탐색**하고 있음을 확인
- AAPL의 `"Cash generated by operating activities"`가 기존 패턴과 일치하지 않아 값이 누락되는 문제 재현
- AAPL의 label을 위한 정규식(`^Cash generated by operating`)을 추가하는 수정안을 제시하고, AAPL의 여러 기간 및 타 기업에 대한 회귀 테스트를 제안

메인테이너 대응

- `get_revenue()`와 `get_capital_expenditures()`에서 이미 사용하던 방식처럼 **XBRL Concept-first lookup → label 기반 fallback**구조로 수정
- 특정 기업의 표현 방식에 의존하지 않고, XBRL 표준 개념을 기준으로 값을 조회하도록 개선
- 동시에 분석 과정에서 `render(standard=True)`의 표준화 매핑이 실제 재무제표에 충분히 적용되지 않는 더 큰 문제도 발견하여 별도 이슈로 분리

결과

* **수정 PR** [`#1089`](https://github.com/dgunning/edgartools/pull/1089)에서 `main`에 병합
* AAPL 10-Q의 운영 현금 흐름이 정상적으로 `$82.627B`로 추출
* 수정 사항이 **v5.52.0 릴리스** [`#1091`](https://github.com/dgunning/edgartools/pull/1091)에 포함
